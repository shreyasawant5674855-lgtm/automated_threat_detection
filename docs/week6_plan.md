## Potential Roadblocks and Contingency Plans

| Roadblock | Contingency Plan |
|---|---|
| Backend fails to start | Check Flask installation and error messages. |
| Frontend cannot connect to backend | Check the Flask server and API URL. |
| AI model gives an error | Check the model file and input features. |
| Database error | Check the SQLite database and table structure. |
| Invalid input | Use the implemented input validation. |
| High number of requests | Use caching and threaded processing. |
| Model performs differently on real data | Test with a larger real-world dataset. |
| Dashboard bugs | Test each dashboard function separately. |
